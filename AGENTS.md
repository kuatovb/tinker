# Правила работы в tinker

Документация на русском языке. Это самостоятельный проект связки нескольких ИИ, выделенный из Inventory 2026-10-05; бизнес-код и конституция Inventory не являются его архитектурой.

- Разработка моста отложена. Без явного поручения пользователя не выполнять открытые задачи и не запускать модели или исполнителей.
- Требования: README, specs/007-ai-agent-collaboration/spec.md, plan.md, tasks.md и контракт. Сначала сверять фактические Git и код, затем исторические отчёты; номера и подтверждённые checkbox сохранять.
- Не изменять глобальные правила, skills, разрешения, модели, авторизацию и посторонние MCP-настройки других ИИ. Не делать доступность Codex обязательной для самостоятельной работы пользователя.
- Перед изменениями проверять git status, сохранять посторонние изменения. Не скрывать ошибки, не подменять неизвестные квоты значениями и не запускать второго исполнителя при неопределённом завершении первого.
- Использовать локально определяемые CLI и Python, относительные коммитируемые пути; не публиковать секреты, сырой вывод, локальные сессии, журналы и окружения.
- После изменения исходников выполнять применимые unittest проверки. Указывать фактические команды, результаты и ограничения. Fake CLI не доказывает живую MCP/E2E интеграцию.
- Conventional Commits включают только согласованный объём; обычный push в origin, без автоматического merge и force-push.
