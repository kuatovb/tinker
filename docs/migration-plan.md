# Перенос связки ИИ в tinker

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Перенос выполняет Codex непосредственно по поручению пользователя от 2026-10-05; правила других ИИ не изменяются.

**Goal:** сохранить связку в `kuatovb/tinker`, очистить Inventory и оставить ручное переключение между ИИ.

**Architecture:** отдельный Python-проект сохраняет структуру исходников, тестов и спецификации 007. Inventory сохраняет ручной workflow и ссылку на новый проект. Удаление исходников выполняется после проверки и публикации копии.

**Tech Stack:** Python 3.12+, Windows, unittest, Git, существующая закреплённая зависимость MCP.

**Spec:** прямое поручение пользователя; исходная спецификация переносится в `specs/007-ai-agent-collaboration/spec.md` проекта tinker.
