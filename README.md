# tinker

Проект для совместной работы нескольких ИИ: подготовка ТЗ, исполнение задач, вопросы, проверка результата и сохранение контекста между сессиями.

## Статус

2026-10-05 проект выделен из QUBE.Inventory. Разработка автоматической связки отложена; выполненная часть и незавершённые задачи сохранены для будущего продолжения. В Inventory пользователь вручную переключается между ИИ и передаёт задания.

Реализованная пара — Codex и Antigravity. Сохранены create/approve, Python API устойчивого запуска, фоновый наблюдатель, хранилище состояния, защита от повторного исполнения и часть контроля квот. Подтверждены **8 из 57 задач**. Наличие зависимости MCP не означает готовый или зарегистрированный MCP-сервер.

Ещё предстоят CLI/MCP start, bootstrap, обмен вопросами и ответами, review/resume, handoff/reconcile/recover и сквозная приёмка. Поддержка других ИИ пока не реализована и потребует отдельного проектирования адаптеров.

## Локальная проверка (Windows, Python 3.12+)

```powershell
python -m venv .venv
./.venv/Scripts/python.exe -m pip install -r scripts/ai/collaboration-requirements.txt
./.venv/Scripts/python.exe -m unittest discover -s tests/ai/collaboration -q
./.venv/Scripts/python.exe scripts/ai/collaboration_bridge.py --help
```

Тесты используют fake CLI и временные Git-копии. Модельные генерации и платные E2E для переноса не нужны. Нативная диагностика доступна отдельно: python scripts/ai/collaboration_bridge.py --json doctor; она требует собственных локальных установок CLI.

Исходная зависимость сохранена: mcp==2.3.0. Окружения, журналы, учётные данные и пользовательская конфигурация ИИ не публикуются. Настройки этого компьютера не являются универсальными путями установки.
